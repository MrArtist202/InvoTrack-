# InvoTrack Backend

## Setup
```bash
npm install
```

## Environment
Create `.env` file with your credentials (already configured)

## Run
```bash
npm run dev
```

## API Endpoints
- `POST /api/auth/register` - Admin signup
- `POST /api/auth/login` - Login
- `GET/POST/PUT/DELETE /api/profiles` - Profiles CRUD
- `GET/POST/PUT/DELETE /api/invoices` - Invoices CRUD
- `GET/POST/PUT/DELETE /api/members` - Members CRUD
